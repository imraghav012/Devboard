# Devboard
Custom development board made for Week 5 of Half-Life.
Made in KiCad, it uses a Raspberry Pi RP2040 on a PCB to control the other components, which can be found in this repository's Bill of Materials (BOM).
It has a USB Type-C port to supply power to and flash the board. It also includes an LDO to control voltage, a X322512MSB4SI crystal oscillator to count time, and USON-8 flash storage.
Tutorial by Kai Pereira: https://blueprint.hackclub.com/starter-projects/devboard, https://github.com/KaiPereira/build-a-devboard/tree/master
